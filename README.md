# Retail Market Segmentation & Cohort Analysis

## Project Context
This project was completed as the **capstone project** for the **Digica Academy Data Analytics** curriculum. 
It demonstrates a foundational application of Python (*Pandas, Seaborn*) to solve real-world business problems, specifically focusing on cohort analysis and customer segmentation.

## Objective
The goal was to apply data manipulation techniques to a raw transactional dataset to identify:
1. Sales trends and high-value geographic markets.
2. Customer retention rates via Cohort Analysis.
3. Product cross-selling opportunities.

## Data Source
[Online Retail II UCI](https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci) - A transactional dataset containing all transactions occurring between 01/12/2009 and 09/12/2011 for a UK-based and registered non-store online retail.

## Tools Used
* **Python** (Data Cleaning, Manipulation)
* **Pandas** (Aggregation, Pivot Tables)
* **Seaborn/Matplotlib** (Visualization)
